# סמן

[הורדה למק](https://github.com/israelor6/saman/releases/latest) · [אתר הפרויקט](https://israelor6.github.io/saman/) · [English](README.md)

סמן מתרגמת טקסט מכל אפליקציה במק שבה אפשר לסמן או להעתיק אותו. סמנו טקסט בדפדפן, במסמך או בצ׳אט וקבלו את התרגום ליד הבחירה.

## הפעלה

פותחים את `build/Saman.app`, בוחרים שתי שפות נתמכות, ומאשרים ל״סמן״ גישה ב־**הגדרות המערכת › פרטיות ואבטחה › נגישות**, ואז חוזרים לאפליקציה שבה קוראים. סמל בועת הדיבור בשורת התפריטים מציג אם ההרשאה פעילה. אם macOS מבקש לפתוח את היישום מחדש, יוצאים מ״סמן״ דרך התפריט ופותחים אותו שוב.

1. מסמנים מילה בלחיצה כפולה, או קטע טקסט בגרירה. סמן מנסה לזהות את שפת הבחירה מתוך הזוג שהוגדר.
2. לוחצים על הבועה הסגולה ליד הבחירה. **⌥⇧T** מתרגם את הבחירה ישירות כשקיצור הדרך זמין.
3. אפשר לגרור את החלונית משורת הכותרת, להפוך את כיוון התרגום בכפתור החיצים, להעתיק את התוצאה ולסגור עם Escape או בלחיצה בחוץ.

באפליקציה שאינה חושפת את הטקסט המסומן דרך הנגישות, מעתיקים אותו עם **⌘C** ובוחרים **תרגום הטקסט שהועתק** בתפריט ״סמן״. המסלול הזה עובד גם ללא הרשאת נגישות.

נדרש macOS 27 ומעלה. אפשר לשנות את הזוג דרך **הגדרות… › שפות התרגום** בתפריט. סמן מציגה זוגות זמינים לשני הכיוונים לפי מנוע התרגום של macOS. בשימוש הראשון macOS עשוי לבקש להוריד את חבילות השפה. אפשר להוריד אותן גם תחת **הגדרות המערכת › כללי › שפה ואזור › שפות תרגום**.

## שפת הממשק

הממשק זמין בעברית ובאנגלית. דרך **הגדרות…** בתפריט סמן אפשר לבחור עברית, אנגלית או **לפי המערכת**. האפשרות לפי המערכת בוחרת את השפה הראשונה בהעדפות macOS שעבורה יש תרגום ממשק. אם אין התאמה, הממשק נפתח באנגלית. בהגדרה ראשונית, שפת התרגום הראשונה מוצעת לפי השפה המועדפת הראשונה של המק, כשהיא נתמכת על ידי מנוע התרגום. זוג שכבר נשמר נשאר הבחירה לתרגום גם אם שפת הממשק משתנה. מספר הגרסה ומספר הבנייה מוצגים ב־**אודות סמן**.

## פתיחה בכניסה למק

בחלון **הגדרות…**, תחת **כללי**, אפשר להפעיל או לכבות **פתיחה בכניסה למק**. סמן נרשמת ישירות אצל macOS כפריט התחברות ונפתחת בשורת התפריטים אחרי הכניסה. אם macOS דורשת אישור, קישור **פתיחת פריטי התחברות** מופיע ליד המתג.

## כשהתפריט עדיין מבקש הרשאת נגישות

בנייה חדשה בחתימה מקומית עשויה לשנות את מזהה החתימה ש־macOS שמרה בהרשאת הנגישות. במקרה כזה המתג בהגדרות יכול להישאר פעיל עבור הגרסה הקודמת.

יוצאים מ״סמן״, מסירים רק את הרשומה שלו תחת **פרטיות ואבטחה › נגישות**, ומוסיפים מחדש את `build/Saman.app` באמצעות **+**. מפעילים את המתג ופותחים את אותו הקובץ. כשההרשאה נקלטת, בתפריט מופיע **הרשאת נגישות פעילה**.

## בנייה ובדיקות

הקוד משתמש ב־AppKit, SwiftUI, Accessibility ו־Apple Translation. נדרשים Xcode Command Line Tools עם SDK של macOS 27. סקריפט הבנייה חותם מקומית את היישום ובונה עבור ארכיטקטורת המק הנוכחי.

```sh
./scripts/build.sh --open
./build/Saman.app/Contents/MacOS/Saman --check
```

הבדיקה המובנית בודקת זיהוי שפה, הצבה ליד גבולות המסך ותרגום בפועל של מילה ומשפט בשני הכיוונים. לאחר מתן ההרשאה, אפשר לבדוק את האייקון מול טקסט באנגלית ב־TextEdit ומול בחירה בדף אינטרנט בדפדפן.

## שיתוף עם חברים

אורזים את האפליקציה מתוך תיקיית הפרויקט ושולחים את קובץ ה־ZIP.

```sh
ditto -c -k --norsrc --keepParent build/Saman.app build/Saman-macOS.zip
```

המקבל מחלץ את הקובץ ופותח את `Saman.app`. בהפעלה הראשונה סמן מציעה להעתיק את עצמה לתיקיית **יישומים** ולפתוח את העותק משם. אפשר לבחור **לא עכשיו** ולהמשיך מהמיקום הנוכחי. לאחר מכן בוחרים שפות ומאשרים נגישות. הגרסה מיועדת למחשבי Apple Silicon עם macOS 27 ומעלה.

הבנייה המקומית משתמשת בחתימת ad hoc. אם macOS חוסמת את הפתיחה ומזהים את הקובץ שנשלח ממקור מהימן, פועלים לפי [הוראות הפתיחה של Apple](https://support.apple.com/en-us/102445). להפצה רגילה מחוץ ל־App Store משתמשים בתעודת Developer ID Application ושולחים את האפליקציה ל־[נוטריזציה אצל Apple](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution).
