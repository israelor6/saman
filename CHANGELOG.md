# Changelog

## 1.5 · 2026-11-25

First public release.

- Translate selected text from a floating bubble or with ⌥⇧T, using Apple Translation.
- Choose a bidirectional language pair, switch directions, and copy the result.
- Drag the translation window. Configure English or Hebrew UI, Accessibility, and Open at Login in Settings.
- Optionally copy Saman to Applications on first launch.
- Preview build for Apple silicon and macOS 27+. The release ZIP is ad hoc signed.
